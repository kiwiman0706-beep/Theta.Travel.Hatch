Theta.xxx.Hatch シリーズの命名に合わせて、アプリ名を **TravelHatch** に改名しました（旧称：たびのたね）。機能は 0.1.0 と同じです。

## インストール
`TravelHatch-0.1.1.apk` をスマホでダウンロードし、「提供元不明のアプリ」を許可してインストールしてください（Android 9 以上）。
0.1.0 を入れている場合は**アンインストールせずに上書き**してください。データはそのまま残ります。

- package: `jp.theta.travelhatch` / versionCode 101
- 署名証明書 SHA-256: `049ca448c59a75ad4e7202cefa0b0559b31b8a8eecca0a87dc622353c42a60c0`

- バックアップ／CSV の書き出しファイル名を `travelhatch-…` に（0.1.0 のバックアップも復元できます）
