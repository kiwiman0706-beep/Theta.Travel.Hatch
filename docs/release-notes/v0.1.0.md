旅行計画・おでかけ記録アプリ「たびのたね」の最初の試作版です。

## インストール
`tabi-no-tane-0.1.0.apk` をスマホでダウンロードし、「提供元不明のアプリ」を許可してインストールしてください（Android 9 以上）。

- package: `jp.theta.travelhatch` / versionCode 100
- 署名証明書 SHA-256: `049ca448c59a75ad4e7202cefa0b0559b31b8a8eecca0a87dc622353c42a60c0`

## できること
- 行きたい場所を貯める（名前・URL共有・音声）。位置は候補から選んで確定し、未確認のものは地図に置きません
- 登録した全スポットを1枚の地図に（行きたい／行った／両方、近い場所はまとめ表示）
- 「雨」「午後から」「1泊」などの条件で、保存済みの場所から理由付きで提案
- しおり：行程、公共交通の往路・復路の乗換メモ、持ち物チェック
- 思い出：しおりから「行った」に変換、計画外のおでかけも記録。一覧・表・地図で見返す
- 端末内保存、JSONバックアップ・復元、CSV書き出し
- Gemini（任意・自分のAPIキー）でスポット整理と旅程の下書き

## 注意
- **実機での動作確認はまだです。** README の実機確認チェックリストを試して、結果を教えてください
- AIの下書き、移動時間の目安は確定情報ではありません。営業時間・料金・空室は公式情報で確認してください
- 写真ファイルはJSONバックアップに含まれません
