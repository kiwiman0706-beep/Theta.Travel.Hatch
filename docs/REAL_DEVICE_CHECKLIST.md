# 実機確認チェックリスト（0.1.0）

0.1.0 は実機・エミュレーターで起動確認をしていません。インストール後に上から順に確認し、うまくいかなかった項目は番号を添えて Issue か次の会話で伝えてください。

## 起動と画面

1. [ ] インストールして起動できる。アイコン（青緑の種）と名前「たびのたね」
2. [ ] 上のステータスバー、下のナビゲーションバーに画面（右上の⚙＋、下の4つのタブ）が隠れていない
3. [ ] 文字入力中にキーボードで入力欄や「保存する」ボタンが隠れない
4. [ ] 端末をダークモードにすると暗い配色になる
5. [ ] 戻るボタン（ジェスチャー）：シートが閉じる → しおり詳細から一覧へ → ホームへ → アプリ終了

## 設定・地図・天気

6. [ ] ⚙設定で出発地を検索（例：自宅の最寄り駅）→候補を選んで保存。ホームに天気（降水確率）が出る
7. [ ] スポットを追加→名前で位置検索→候補を選ぶと小さな地図にピンが立つ。地図をタップしても位置を変えられる
8. [ ] 位置を選ばずに保存すると「位置未確認」になり、スポット地図には出ず下に名前が出る
9. [ ] スポット地図で拡大・縮小・ピンのタップ→「くわしく見る」が動く。近い場所は数字でまとまる
10. [ ] スポット詳細の「地図アプリで開く」で Google マップ等が開く

## 入力系

11. [ ] 🎤で音声入力できる（ホームと追加画面）
12. [ ] ブラウザや Google マップの「共有」→たびのたね で、追加画面にURLと名前が入る
13. [ ] 思い出に写真を複数追加でき、保存後も表示される（向きが正しい）
14. [ ] 削除の確認ダイアログが出て、「OK」で削除・「キャンセル」で残る

## しおり・思い出

15. [ ] ホームで条件を選ぶ→候補→「しおりの下書きを作る」→行程・移動・持ち物を編集できる
16. [ ] 公共交通で往路2区間・復路1区間を登録→乗換時間が表示される
17. [ ] 「行った記録にする」→思い出タブに出る→一覧・表・地図で見える
18. [ ] アプリを完全に終了して開き直しても、入力したものが全部残っている

## データ

19. [ ] 設定→バックアップを書き出す（JSON）→保存先を選べる
20. [ ] 思い出／スポットのCSVを書き出し、SmoothCSV や Excel で文字化けせず開ける
21. [ ] バックアップから復元できる（件数の確認ダイアログが出る）
22. [ ] 設定→「新しい版を確認」で「最新です（0.1.0）」と出る

## Gemini（キーを持っている場合）

23. [ ] 設定に API キーを入れる→スポット追加で「✦ AIで特徴を整理」→屋内外・タグ等が入る
24. [ ] ホームの候補で「✦ AIで下書き」→要確認事項付きの下書きができる
25. [ ] モデル名エラーが出たら、設定のモデル名を現在のもの（例：`gemini-2.5-flash`）に変えて再試行できる
