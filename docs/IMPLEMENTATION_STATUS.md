## 構想にあって 0.1.0 に入れていないもの

- Places による施設情報・営業時間の取得、Routes による実際の移動時間、乗換検索・時刻表の自動取得
- 時間帯別の降水予報、旅程の日付の天気（現在は出発地の今日〜3日の日別予報のみ）
- 写真を含むバックアップ（ZIP）、自動バックアップ、PC表示、家族共有・同期
- 写真や位置情報からの過去履歴の取り込み
- 日英UI
