## 発言と区別する提案事項

以下は会話中にこちらが整理・提案した設計であり、ユーザーから細部まで確定指示されたものではありません。

- 「場所」「旅程」「訪問」を別レコードにして同じ場所への再訪を扱う。
- スポットの状態を「行きたい」「行った」「両方」で切り替える。
- 天気・施設・経路の現在情報とAIの文章を区別し、確認日時や出典を表示する。
- 乗換情報は初期版では手入力し、時刻表・経路検索との連携を後から加える。
- 持ち物は旅程別のチェックリストにする。
- 端末内保存から始め、PC表示や家族共有は後続段階にする。

要望から自然に導いた項目も含みます。開発中にユーザーが修正した場合は、その新しい指示を優先してください。
